# **App Name**: ORVYRA

## Core Features:

- Lightning Intake: AI-powered tool that parses LinkedIn URLs or unstructured pitches to automatically generate builder profiles without manual data entry.
- Builder Feed: Text-heavy directory of founders using Firestore for real-time synchronization, sortable by 'Seeking Co-founder' or 'Mentorship' states.
- Resource Vault: Structured repository of startup execution modules presented as a task-based checklist for engineering-led company building.
- One-Click Bridge: Immediate message thread initiation system that bypasses traditional profile approval loops to facilitate high-velocity connection.
- Focus Auth: Rapid onboarding sequence using Firebase Auth for minimal friction and technical validation.

## Style Guidelines:

- Background: Obsidian Black (#0C0C0D) for high-performance visual depth. Primary: Sharp Steel White (#F2F2F5) for maximum legibility. Accent: Technical Blue (#60A5FA) for precise call-to-actions and indicators.
- Primary and Body: 'Inter', a grotesque sans-serif chosen for its objective and modern technical aesthetic, prioritized for dense, high-contrast layouts.
- Monochrome, ultra-thin line icons with zero filled states to maintain a tool-first builder aesthetic.
- Modular grid with zero-radius (square) edges; use of strict hairline borders (#2D2D30) and glassmorphism for elevation over flat black surfaces.
- Instantaneous UI transitions (under 150ms) to mirror the application's emphasis on high-velocity builder productivity.
